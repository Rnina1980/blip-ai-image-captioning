
# AI Image Captioning with BLIP and Gradio

A Python AI application that generates natural-language image captions using Hugging Face's pretrained BLIP model.

## Features

- Generate captions from uploaded images
- Interactive Gradio web interface
- Extract images from webpages using BeautifulSoup
- Automatically generate and save captions to a text file

## Technologies

- Python
- Hugging Face Transformers
- BLIP
- PyTorch
- Gradio
- BeautifulSoup
- Pillow
- Requests

## Run the Application

Install dependencies:

pip install gradio==5.23.2 transformers==4.38.2 torch==2.2.1 numpy==1.26.4 Pillow requests beautifulsoup4

Start the application:

python3 image_captioning_app.py

Open the local or forwarded Gradio URL.
